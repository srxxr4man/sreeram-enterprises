## 📌 About the Project

**Sreeram Enterprises** is the official corporate website developed to establish a professional digital presence for the enterprise, founded and directed by **R. Amruthanadhan**.

The platform serves as a centralized digital showcase for the company's business offerings, brand identity, leadership, and core values.

Built using **React and Vite**, with Tailwind CSS for styling, the website focuses on delivering a clean, modern, and responsive browsing experience across desktops, tablets, and smartphones.

The project emphasizes professional branding, accessible navigation, modular component architecture, and a seamless user experience.

## 🏗️ Component Architecture

The application follows a modular React component architecture, separating different website sections into reusable components.

| Component | File Path | Responsibility |
|---|---|---|
| 🧭 Navbar | `src/components/Navbar.jsx` | Responsive header and mobile navigation |
| 🏠 Hero | `src/components/Hero.jsx` | Brand introduction and call-to-action |
| 🛍️ Products | `src/components/Products.jsx` | Product catalog and offerings |
| 👔 Proprietor | `src/components/Proprietor.jsx` | Founder profile and company journey |
| 📞 Footer | `src/components/Footer.jsx` | Contact details, location, and business hours |

## ⚙️ How It Works

1. **⚡ Vite Development Pipeline:** Uses native ES modules during development, providing fast startup and Hot Module Replacement (HMR). Production builds generate optimized static assets.

2. **🧩 Component-Based Architecture:** Each website section is developed as an independent React component, making the application easier to maintain and extend.

3. **🎨 Utility-First Styling:** Tailwind CSS provides reusable utility classes for consistent styling and efficient CSS generation.

4. **📱 Responsive Layout System:** CSS Flexbox, Grid, and responsive breakpoints adapt the interface to different screen dimensions.

5. **☁️ Deployment Pipeline:** The production build is deployed through Vercel for public website access.

## 🖥️ Getting Started

Want to run the project locally?

### 1. Clone the Repository

```bash
git clone (https://github.com/srxxr4man/sreeram-enterprises.git)
```

### 2. Navigate to the Project Directory

```bash
cd sreeram-enterprises
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
